Fucntionality
This project simulates double pendulum and using this to create a drawing tool. Many aspects of the double pendulum is configurable from mass, length of arms, gravity.
The drawing happens by tracing the path of the bop at the bottom of the pendulum.
The pendulum can be hidden by pressing "R"
Path can be Traced by pressing "T"

Reflection
Looking at how summer used the pendulum gave me insight that was not directly available for me.
The confusion the I saw as my haphazardly put together UI, reminded me that there are functionalities and quirks that only I understood.
I had a lot of text for explanation, and no explanationg of what the sliders did. 
summer did not create shapes that I imagined someone would make with my tool. She did not explore the pattern that I thought people would be interested int.
Part of the problem is that she almost had no guidance from me, or no example drawn to guide the user. It was truly just and empty canvas. 
Even in a simple program like this, the communication with designer and user seems like a daunting task. 

Outcomes.
I am very please with my tool, the imperfect quirks, the emphmerial nature of the tool all contributes to the temporary nature of the drawing. I like that no two drawing can be replicated.
